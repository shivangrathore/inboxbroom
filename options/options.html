Setup check

Gmail tabKeep one open; the extension works inside it.
Local AI (Ollama)Optional. Without it only bulk rules run.
Labels in GmailTaxonomy labels for kept mail.

Flow: Preview → review tab → Confirm. Nothing is deleted without the review unless you use Clean now.

Rules

Bulk rules act on everything their Gmail search returns. AI rules run the search, score each mail with your local model and act only on junk; kept mail gets a label. Actions: Delete = Trash (30-day undo), Archive, Label + archive (Gmail “Move to”). Inbox only forces in:inbox so archived mail is never touched. Rules run top to bottom.

Query ideas
  • category:updates older_than:14d -from:(bank.com OR gov.in)
  • from:(noreply@linkedin.com OR info@quora.com)
  • is:unread older_than:60d -is:important
  • Purge what the cleaner labeled, after a month (turn Inbox only off): label:Cleaned older_than:30d → Delete

Always keep

One sender or domain per line. Appended to every rule as -from:(…). “Always keep sender” in the review adds here.

Local AI (Ollama)

Each mail's sender, subject and preview go to the model, which returns junk/keep plus a label. Ollama keeps everything on your machine. A cloud provider sends that text to their servers; the key is stored only in this extension's storage.

OpenRouter: https://openrouter.ai/api/v1 · Groq: https://api.groq.com/openai/v1 · Gemini: https://generativelanguage.googleapis.com/v1beta/openai
claude-opus-5-5 default; claude-haiku-5-5 is the cheap option for bulk triage. Uses low effort and Anthropic's refusal fallback.
Lower = more aggressive. 60 is a good start; 50 if it still misses junk.

Labels

auto copies your existing labels ([Finance] → [{name}]); or set {name}, [{name}], @{name}…
LabelColorIn sidebar

Organize labels creates missing ones, renames plain ones to your style, sets sidebar visibility and color, all through Gmail's own dialogs. Gmail sorts the sidebar alphabetically; “pin” = show, the rest sit under More.

Inbox expiry

The inbox is a queue, the archive is forever. Anything still in the inbox with a label older than its lifetime goes to Trash on the next run (shown in the preview first). * = inbox mail without any of these labels. Archived, starred and important mail are never touched. Blank or 0 = keep forever.

About

Inbox Broom drives the Gmail web page like you would by hand. No API keys; nothing leaves your machine except calls to your local Ollama. Source, issues and updates on GitHub. MIT.
