Rules

Run top to bottom. Bulk rules act on everything their Gmail search returns. AI rules score each mail and act only on junk; kept mail gets a label.

Query ideas
  • category:updates older_than:14d -from:(bank.com OR gov.in)
  • from:(noreply@linkedin.com OR info@quora.com)
  • is:unread older_than:60d -is:important
  • Purge what the cleaner labeled, after a month (turn Inbox only off): label:Cleaned older_than:30d → Delete

Labels

Kept mail gets one label, from your existing Gmail labels first.

Suggested labels
Created only when the AI picks one that doesn't exist. Comma separated.
Never use
Labels the AI must not assign.
Name style
Default [{name}] avoids names Gmail reserves (Personal, Travel, Social…). auto copies your existing labels; or {name}, @{name}…
Color & sidebar
Applied by Organize labels through Gmail's own menus. Gmail sorts the sidebar alphabetically; "show" pins it, the rest sit under More.
LabelColorIn sidebar

Inbox expiry

The inbox is a queue, the archive is forever. Mail still in the inbox past its label's lifetime goes to Trash on the next run (shown in the preview first). Archived, starred and important mail is never touched.

LabelDelete after (days)

Always keep

One sender or domain per line, appended to every rule as -from:(…). "Always keep sender" in the review adds here.

About

Inbox Broom drives the Gmail web page like you would by hand. No API keys for Gmail; nothing leaves your machine except calls to the AI provider you choose. GitHub · MIT.
