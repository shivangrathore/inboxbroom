Gmail Inbox Cleaner – Settings

Drives the Gmail web page like you would by hand: runs each search, selects results, applies the action. No API keys. Keep a Gmail tab open; the run is visible there.

Rules

Bulk rules act on everything the Gmail search returns. AI rules run the search, score each mail with your local model and act only on junk. Actions: Label = apply label + archive (Gmail “Move to”), Archive = out of inbox, Delete = Trash (purged after 30 days). Inbox only forces in:inbox so archived/labeled mail is never touched. Rules run top to bottom.

OnTypeNameQueryActionLabelInbox onlyPages
Query ideas
  • category:updates older_than:14d -from:(bank.com OR gov.in)
  • from:(noreply@linkedin.com OR info@quora.com)
  • is:unread older_than:60d -is:important
  • Purge what the cleaner labeled, after a month (turn Inbox only off): label:Cleaned older_than:30d → Delete

Always keep (allowlist)

One sender or domain per line. Appended to every rule as -from:(…).

Local AI (Ollama)

Runs fully on your machine. Each mail gets a junk score 0–100 from sender, subject and preview; at or above the threshold it is cleaned.

Expire labeled mail

Mail the AI labeled is kept in the inbox. Give a label a lifetime and anything with that label older than N days is moved to Trash on the next run (shown in the preview first). Blank or 0 = keep forever.
